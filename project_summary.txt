SPEAKING AGENT - DEVELOPMENT TIMELINE & TECH STACK

==================================================
WHAT WE HAVE BUILT
==================================================

Phase 1: Foundation & Authentication
- Mobile App Frontend (React Native & Expo) initialized.
- FastAPI Backend initialized with MySQL database connection.
- Complete User Authentication:
  * Secure password hashing (bcrypt).
  * JWT Token generation and validation.
  * Login & Registration endpoints.
  * Auth-protected routes using dependency injection.

Phase 2: Voice Recording Foundation
- Microphone permissions handling in the mobile app.
- Custom "useAudioRecorder" hook to manage recording states (start, stop, playback).
- RecordingScreen UI with visual feedback (recording state, timer, processing).
- Audio file saving and playback logic on the device.

Phase 3: AI Backend Integration
- Speech-to-Text Pipeline: Handled multipart/form-data audio uploads to the backend.
- Local Whisper Integration: Built the initial STT service using local Python whisper.
- LLM English Coach: Integrated Groq API (LLaMA 3) to act as an English coach, returning structured feedback based on the user's spoken transcript.

Phase 4: Cloud STT & Optimization (Day 14)
- Migrated STT from Local Whisper to Groq Cloud Whisper (whisper-large-v3) for instant transcription.
- Refactored the frontend to immediately upload audio to the new "/transcribe" endpoint when recording stops.
- Displayed the AI's transcription natively on the mobile screen.
